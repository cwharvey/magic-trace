* print perf command

it is a hidden developer flag. To use it, you must:

  1. Set the environment variable MAGIC_TRACE_DEBUG=1
  2. Pass the hidden flag -z-print-perf-commands to your magic-trace command.

  For example:

    MAGIC_TRACE_DEBUG=1 magic-trace run -z-print-perf-commands -- ./demo/ptwrite_queue

  When you run this, it will echo the exact perf record and perf script commands right to your terminal before executing them.
